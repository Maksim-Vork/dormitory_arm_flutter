# 🚀 Сборка Windows версии через GitHub Actions

## 📋 Что нужно сделать (3 простых шага):

### 1️⃣ Создать репозиторий на GitHub
```bash
git init
git add .
git commit -m "Initial commit"
# Создать репозиторий на github.com и подключить:
git remote add origin https://github.com/ВАШ_НИК/dormitory_arm_flutter.git
git push -u origin main
```

### 2️⃣ Запустить сборку
**Способ А - Автоматический (рекомендуется):**
```bash
# Создать тег релиза (автоматически запустит сборку)
git tag v1.0.0
git push origin v1.0.0
```

**Способ Б - Ручной:**
- Зайти в репозиторий на GitHub
- Перейти в "Actions" → "Build Windows App" → "Run workflow"

### 3️⃣ Скачать готовую сборку
- GitHub соберет .exe файл автоматически (5-10 минут)
- Скачать из раздела "Actions" → "Artifacts" 
- Или из "Releases" если создавали тег

## 📦 Что получится:
- `dormitory_arm_flutter_windows.zip` - готовое приложение
- `release_info.md` - инструкция по установке
- Полностью автономное приложение без установки

## 🔧 Дополнительно:
- **Бесплатно** - GitHub Actions бесплатен для публичных репозиториев
- **Автоматически** - каждая новая версия собирается сама
- **Кросс-платформа** - работает на Windows 10/11

## 📝 Требования:
- Аккаунт на GitHub
- Git установленный на Mac
