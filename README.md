# 🏢 АРМ Общежития Колледжа (Flutter + SQLite)

Полноценная desktop версия системы управления общежитием на Flutter с локальной базой данных SQLite.

## 🚀 Особенности

- **Полностью автономное приложение** - работает без интернета
- **Локальная база данных SQLite** - все данные хранятся на компьютере
- **Современный Material Design 3 интерфейс**
- **Кроссплатформенность** - работает на Windows, macOS, Linux
- **Быстрый старт** - один exe файл для Windows

## 📋 Функционал

1. **👤 Управление студентами** - добавление, редактирование, удаление студентов
2. **🏠 Управление комнатами** - управление номерами комнат и их вместимостью
3. **🛏 Заселение/выселение** - контроль проживания студентов
4. **💳 Учёт платежей** - регистрация и учёт оплаты проживания
5. **🧺 Учёт стирки** - контроль выдачи чистого белья и химчистки
6. **📊 Панель статистики** - общая статистика по общежитию

## 🔧 Технологии

- **Frontend**: Flutter 3.41.2
- **База данных**: SQLite (через sqflite)
- **State Management**: Provider
- **UI**: Material Design 3
- **Дата/время**: intl

## 🚀 Запуск на macOS

### Требования
- Flutter SDK 3.41.2+
- Xcode (для macOS)
- macOS 10.14+

### Запуск
```bash
# Перейти в папку проекта
cd dormitory_arm_flutter

# Установить зависимости
flutter pub get

# Запустить на macOS
flutter run -d macos
```

## 🚀 Запуск на Windows

### Требования
- Flutter SDK 3.41.2+
- Visual Studio 2022 с C++ development tools
- Windows 10+

### Запуск
```bash
# Перейти в папку проекта
cd dormitory_arm_flutter

# Установить зависимости
flutter pub get

# Запустить на Windows
flutter run -d windows
```

### Сборка exe файла
```bash
# Собрать релизную версию
flutter build windows --release

# Готовый exe файл будет в:
# build/windows/runner/Release/dormitory_arm_flutter.exe
```

## 🗄 База данных

Приложение автоматически создает файл базы данных `dormitory.db` в папке приложения при первом запуске.

### Структура БД:
- `students` - студенты
- `rooms` - комнаты
- `settlements` - заселения
- `payments` - платежи
- `laundry` - стирка
